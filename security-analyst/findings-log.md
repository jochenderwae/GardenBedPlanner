# Security findings log

Dated, append-only log for the `security-analyst` agent (`.claude/agents/security-analyst.md`). Every finding - fixed, deferred to a backlog ticket, or accepted as a known risk given this project's single-user/no-auth-in-v1 scope - gets an entry here, regardless of whether it was also fixed in the same pass. This is the durable audit trail; don't rely on scattered comments elsewhere for security history.

Entry shape: date, area, what/where, severity in this app's actual context, outcome (fixed / ticket #N / accepted risk and why).
